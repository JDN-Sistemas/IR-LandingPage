## Observações de Design e Tom de Voz

### Paleta de Cores (extraída da logo IR)

A logo utiliza um traço em marrom/terracota sobre fundo branco/off-white, transmitindo sofisticação, acolhimento e organicidade — segue paleta sugerida para o site:

| Uso | Cor | Hex |
|---|---|---|
| **Primária** (marca, títulos, ícones, traços) | Marrom terracota (cor da logo) | `#7A3B12` |
| **Primária escura** (hover, textos de destaque, rodapé) | Marrom café escuro | `#5A2A0D` |
| **Secundária / Acento** (botões CTA, links, detalhes) | Marrom-avermelhado / ferrugem | `#A85A2A` |
| **Acento claro** (badges, hover suave, ícones leves) | Terracota claro | `#C98B54` |
| **Fundo principal** | Off-white / marfim (fundo da logo) | `#FAF6F0` |
| **Fundo secundário** (seções alternadas) | Bege claro | `#F0E6D8` |
| **Texto principal** | Marrom quase preto | `#3A2317` |
| **Texto secundário / legendas** | Marrom acinzentado | `#8C7365` |
| **Bordas / divisores** | Marrom claro suave | `#D9C4AE` |

> Racional: manter o marrom da logo como cor de identidade forte (títulos, ícones, header/rodapé), usar off-white/bege como base neutra e acolhedora, e reservar o terracota/ferrugem para CTAs e elementos de ação — criando contraste suficiente sem sair da paleta original da marca.

- **Tom de voz:** acolhedor, mas profissional e técnico — equilíbrio entre humano e especialista
- **Tipografia:** fontes sóbrias e legíveis (ex: Inter, Poppins, Montserrat) — títulos podem usar uma fonte com leve toque manuscrito/serifado para dialogar com o traço cursivo da logo
- **Imagens:** preferir fotos reais de ambientes corporativos humanizados, evitar bancos de imagem genéricos quando possível
- **Uso da logo:** manter sempre em `#7A3B12` (ou variação escura `#5A2A0D`) sobre fundos claros (`#FAF6F0` ou branco), garantindo contraste e legibilidade

## Stack Técnica Recomendada

- **Framework:** [Next.js](https://nextjs.org/) (React) — utilizando App Router
- **Estilização:** Tailwind CSS, com as cores da paleta configuradas em `tailwind.config` (tokens: `primary`, `primary-dark`, `accent`, `accent-light`, `background`, `background-alt`, `text`, `text-secondary`, `border`)
- **Componentização:** cada seção do documento (Hero, Sobre, Serviços, Metodologia, Sobre o Rafael, Diferenciais, Depoimentos, FAQ, CTA, Contato) como um componente React independente em `/components`
- **Formulário de contato:** rota de API (`/app/api/contact/route.ts`) ou integração com serviço externo (ex: Resend, Formspree)
- **Deploy sugerido:** Vercel (integração nativa com Next.js)
- **Fontes:** carregadas via `next/font` (ex: Inter/Poppins para corpo, fonte com toque manuscrito para títulos de destaque)
- **Imagens:** componente `next/image` para otimização automática, incluindo a logo e fotos do Rafael Ita
